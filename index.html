Sistema IoT de Monitoramento Ambiental com ESP32, Node-RED e MQTT

Desenvolvimento de um sistema de Internet das Coisas para monitoramento ambiental utilizando o microcontrolador ESP32 como dispositivo de borda. O sistema integra sensores de temperatura, umidade, luminosidade e distância, comunicando-se via protocolo MQTT com um broker central e expondo uma API HTTP local — com automação de rotinas via Node-RED.
